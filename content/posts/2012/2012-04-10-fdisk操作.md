好久没用到fdisk等操作了= =在这,趁这个机会好好的记录下...(终于说道这个故事的主线了!)

```bash

fdisk  /dev/sda

```
<ul>
	<li>p   列出当前分区表</li>
	<li>n  添加新分区
<ol>
	<li>回车  选择开始的块地址,直接回车默认就可以了</li>
	<li>+512G   输入要添加分区的大小(M啊K啊G啊都能识别的= =好高级!)</li>
	<li>回车  确定</li>
</ol>
</li>
	<li>w 写入并退出</li>
</ul>

```bash
partprobe
```

更新当前分区表给内核 这一步非常重要, 否则你的分区重启才能看到.

```bash

mkfs.ext3 /dev/sda1
```
