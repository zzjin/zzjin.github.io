<h1>
	Chapter 1: Hybrid Desktop/Internet Applications</h1>
With a implement of a weather app to introduce it.<br />
within it,I see a template class "QCache".<br />
In fact it use the qHash to store data and afford quick search. In the Qt4.7.2&#39;s doc It says:<br />
The <span >advantage</span> of using QCache over some other key-based data structure (such as<span class="Apple-converted-space">&nbsp;</span><span >QMap</span><span class="Apple-converted-space">&nbsp;</span>or<span class="Apple-converted-space">&nbsp;</span><span >QHash</span>) is that <span ><span >QCache automatically takes ownership of the objects that are inserted into the cache and deletes them to make room for new objects, if necessary.</span> </span>When inserting an object into the cache, you can specify a<span class="Apple-converted-space">&nbsp;</span><i>cost</i>, which should bear some approximate relationship to the amount of memory taken by the object. When the sum of all objects&#39; costs (<span >totalCost</span>()) exceeds the cache&#39;s limit (<span >maxCost</span>()), <span ><span >QCache starts deleting objects in the cache to keep under the limit, starting with less recently accessed objects.</span></span><br />
总的来说呢,就是这个QCache类可以自动管理里面的数据.切删除放不下的chache的时候回首先从最少使用的那些数据开始删除...很自动化的一个东西.<br />
